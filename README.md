# ⚡ Omar Sherif — Personal Portfolio

A lightweight, responsive, and high-performance personal portfolio engineered for speed, fluid glassmorphic interactions, and clean visual hierarchy.

---

## 🌟 Features

* **⚡ 60 FPS Performance**: Built with strict GPU layer isolation (`will-change`, `translate3d`, `contain`), zero layout shift, and instant touch velocity response.
* **✨ Glassmorphic Segmented Navigation**: Floating navigation dock and category filter bar equipped with dynamic glider indicators.
* **🃏 Dual 3D Facing Stack Decks**: Independent, interactive 3D card carousels showcasing Notion templates and technical projects side-by-side.
* **🏆 Interactive Filterable Certifications**: Real-time category filtering for 20 verified credentials with company-based sorting.
* **🌙 Bicultural Typography Architecture**: Uses `Inter` for clean English text paired with native Arabic calligraphy typography.
* **🎯 Subpixel Anti-Aliasing**: Hardware-accelerated card tilt tracking with zero edge artifacts or idle hover breaks.

---

## 🛠 Tech Stack

The website is built purely with native web technologies—zero heavy frameworks or bloatware:

* **HTML5**: Semantic markup & structured accessibility.
* **CSS3**: Custom CSS variables, glassmorphism, 3D CSS transforms, and GPU acceleration.
* **JavaScript (Vanilla)**: Frame-rate independent animation engine, mid-viewport scrollspy, and interactive deck controllers.
* **Google Fonts**: Inter font family.
* **Icons**: Font Awesome 6 & Simple Icons.
